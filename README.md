## 📌 Overview
 
Doura Mondo is a comprehensive full-stack web application built with Symfony 6.4 that revolutionizes tourism and travel management. The web platform empowers users to discover, book, and manage tourism activities and travel packages through an intuitive browser interface, while providing administrators with powerful tools for travel and activity management, supplier coordination, and real-time analytics.
 
This web application shares the same database and business logic as the JavaFX desktop application, enabling seamless data synchronization across multiple platforms. The application integrates cutting-edge technologies including AI-powered recommendations, interactive mapping, real-time weather integration, email notifications, and comprehensive analytics.
 
**Repository Type:** Web Application (Symfony)  
**Sister Project:** JavaFX Desktop Application  
**Shared Database:** MySQL (both desktop and web use the same database)

## ✨ Features
 
### 👥 User Module (Authentication & Profile)
- User registration with email verification
- Secure login with BCrypt passwords
- User profile management
- Password reset via OTP
- View booking history
- Manage favorite activities
### 🧳 Voyage Module (Travel Plans)
- Create multi-day itineraries
- Plan activities day-by-day
- Drag-and-drop scheduling
- Auto-calculate trip duration
- View weather forecast per day
- Calculate total budget
- Export itinerary as PDF
- Share plans with friends
- Collaborative planning
### 🏞️ Activity Module (Browse & Search)
- Browse all tourism activities
- Search by name/location/category
- Filter by price, duration, category
- View detailed activity information
- Real-time availability status
- Activity ratings & reviews
- Auto-filled descriptions (Wikipedia API)
- Auto-fetched images (Pexels API)
### 📅 Reservation Module (Booking System)
- Book activities with date selection
- Choose number of participants
- Real-time availability checking
- Confirmation emails
- View booking history
- Cancellation support
- Booking status tracking
### ⭐ Review Module (Avis)
- Rate activities (1-5 stars)
- Write detailed reviews
- Read other traveler reviews
- Translate reviews to other languages
- Edit/delete own reviews
- Review moderation (admin)

**Frontend:** Twig, Bootstrap 5, JavaScript
